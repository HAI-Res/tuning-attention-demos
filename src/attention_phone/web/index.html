The native app reaches two things a browser cannot: AirPods head orientation and a 100 Hz sensor rate. Everything else on this page is the same instrument.

Per-axis numbers under each sensor. Useful once, to check units — a phone at rest should read accel ≈ 0 and gravity ≈ 9.81.

Rate cap

A cap, not a request. The browser decides how fast it delivers motion — about 60 Hz on iOS — and this only thins what is sent. The number beside each sensor is what is actually going out.

Set up by link

This page takes the same kind of configure link the app does, as query parameters: ?room=k7f2q&name=Ada&on=accel,gyro,audio&autostart=1&rate=50&values=1. Keys left out are left alone.
